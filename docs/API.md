# API

Base path `/api/v1`. Interactive documentation is generated by FastAPI at `/api/docs`
(OpenAPI JSON at `/api/openapi.json`) once the backend is running; that is the authoritative
reference for request and response fields.

## Conventions

Success:

```json
{ "data": { }, "meta": { "request_id": "..." } }
```

Failure:

```json
{ "error": { "code": "SLOT_UNAVAILABLE", "message": "...", "details": { } }, "meta": { "request_id": "..." } }
```

- Authentication: `Authorization: Bearer <access token>`. The refresh token is an HttpOnly
  cookie and is never read by JavaScript.
- `POST /auth/refresh` requires the header `X-Requested-With: carebridge`.
- `POST /appointments` and `POST /appointments/{id}/reschedule` accept an `Idempotency-Key` header.
- A record the caller may not see returns **404**, not 403, so its existence is not revealed.
- Times are ISO 8601 in UTC. Date filters (`on_date`) are interpreted in Asia/Kolkata.

## Endpoints

### Authentication and profile

| Method | Path | Who | Purpose |
|---|---|---|---|
| POST | `/auth/register` | anyone | Create a patient or caregiver account |
| POST | `/auth/login` | anyone | Sign in |
| POST | `/auth/refresh` | cookie | Rotate the refresh token, get a new access token |
| POST | `/auth/logout` | cookie | Revoke the current refresh token |
| POST | `/auth/change-password` | signed in | Change password, sign out other devices |
| GET, PATCH | `/me` | signed in | Profile, language, patient details |
| GET | `/me/notifications` | signed in | `?unread_only=true` supported |
| POST | `/me/notifications/read-all`, `/me/notifications/{id}/read` | signed in | Mark as read |

### Directory and navigation

| Method | Path | Who | Purpose |
|---|---|---|---|
| GET | `/specialties`, `/hospitals`, `/localities` | signed in | Reference lists |
| GET | `/doctors` | signed in | Filters: `specialty_id`, `hospital_id`, `locality`, `q`, `on_date`. Includes next free slots |
| GET | `/affiliations/{id}`, `/affiliations/{id}/slots` | signed in | One doctor at one hospital, and free slots (`date_from`, `date_to`) |
| GET | `/navigation/concerns` | signed in | Common concerns to choose from |
| POST | `/navigation/suggest` | signed in | `{text}` or `{concern_key}` → department suggestions and an emergency flag |

### Appointments

| Method | Path | Who | Purpose |
|---|---|---|---|
| POST | `/appointments` | patient, caregiver with `BOOK_APPOINTMENTS` | `{slot_id, patient_id, reason_text?}` |
| GET | `/appointments` | patient, caregiver with `VIEW_APPOINTMENTS` | `patient_id`, `scope=upcoming|past|all` |
| GET | `/appointments/{id}` | patient, permitted caregiver, the doctor, the hospital's admin | Fields vary by viewer |
| POST | `/appointments/{id}/cancel` | patient, caregiver with `CANCEL_APPOINTMENTS` | `{reason?}` |
| POST | `/appointments/{id}/reschedule` | patient, caregiver with `RESCHEDULE_APPOINTMENTS` | `{new_slot_id}` |
| GET | `/doctor/appointments` | doctor | `on_date` |
| POST | `/appointments/{id}/complete`, `/no-show` | the doctor, the hospital's admin | Record the outcome |

### Before and after the visit

| Method | Path | Who | Purpose |
|---|---|---|---|
| GET, PUT | `/appointments/{id}/intake` | read: patient, caregiver with `VIEW_PRECONSULTATION_INFORMATION`, doctor. Write: patient | Pre-visit answers |
| POST | `/appointments/{id}/summary` | patient | Generate the AI summary. 503 `AI_UNAVAILABLE` when no model is configured |
| GET, PATCH | `/appointments/{id}/summary` | patient always; others only after the patient marks it reviewed | Patient edits or approves; doctor adds a correction |
| GET, PUT | `/appointments/{id}/notes` | doctor | Private notes |
| GET, PUT | `/appointments/{id}/follow-up` | read: patient, caregiver with `VIEW_FOLLOW_UP_INFORMATION`, doctor. Write: doctor | Follow-up instructions |

### Waiting list

| Method | Path | Who | Purpose |
|---|---|---|---|
| POST | `/waiting-list` | patient, caregiver with `BOOK_APPOINTMENTS` | `{affiliation_id, patient_id}` |
| GET | `/waiting-list` | same | `patient_id` → `{entries, offers}` |
| DELETE | `/waiting-list/{entry_id}` | same | Leave |
| POST | `/waiting-list/offers/{id}/accept`, `/decline` | same | Answer an offer |

### Caregivers

| Method | Path | Who | Purpose |
|---|---|---|---|
| GET | `/care/permissions` | signed in | The seven permissions and the consent text version |
| POST | `/care/requests` | caregiver | `{patient_identifier, permissions}`. Always answers 202 |
| GET | `/care/relationships` | patient, caregiver | Own relationships |
| POST | `/care/relationships/{id}/approve` | patient | `{permissions}` |
| POST | `/care/relationships/{id}/reject` | patient | |
| PATCH | `/care/relationships/{id}/permissions` | patient | `{permissions}` |
| POST | `/care/relationships/{id}/revoke` | patient | `{reason?}` |
| GET | `/care/relationships/{id}/history` | patient, that caregiver | Consent history |

Permissions: `VIEW_APPOINTMENTS`, `BOOK_APPOINTMENTS`, `RESCHEDULE_APPOINTMENTS`,
`CANCEL_APPOINTMENTS`, `RECEIVE_REMINDERS`, `VIEW_FOLLOW_UP_INFORMATION`,
`VIEW_PRECONSULTATION_INFORMATION`.

### Assistant and speech

| Method | Path | Who | Purpose |
|---|---|---|---|
| GET | `/assistant/status` | signed in | `{provider, status, mode}` where mode is `ai` or `guided` |
| POST | `/assistant/sessions` | patient, caregiver | `{language, patient_id?}` → first reply |
| POST | `/assistant/sessions/{id}/turns` | owner | `{text?, option_value?, input_mode, stt_confidence?, language?}` |
| POST | `/assistant/sessions/{id}/confirm` | owner | `{token}` → books the slot shown in the confirmation |
| GET | `/speech/status` | signed in | `{available, provider}` |
| POST | `/speech/token` | patient, caregiver | Short-lived Azure token. 503 `SPEECH_UNAVAILABLE` when not configured |

### Hospital administration

All under `/admin/hospitals/{hospital_id}`; the caller must be an admin of that hospital.

| Method | Path | Purpose |
|---|---|---|
| GET | `` and `/overview` | Hospital details and counts |
| GET, POST | `/departments` | List, add |
| GET, POST | `/doctors` | List, add a doctor (creates the account if needed) |
| PATCH | `/affiliations/{id}` | Fee, active flag |
| GET, POST | `/affiliations/{id}/schedules` | Weekly hours |
| DELETE | `/schedules/{id}` | Remove weekly hours |
| POST | `/affiliations/{id}/slots/generate` | `{days}` |
| GET | `/affiliations/{id}/slots` | `on_date` |
| POST | `/slots/{id}/block`, `/unblock` | Only free or blocked slots |
| GET | `/appointments` | `on_date`, `status`. No clinical text |
| POST | `/appointments/{id}/cancel` | `{reason}` required |

### Health

| Method | Path | Purpose |
|---|---|---|
| GET | `/health` | Process is up |

## Error codes

| HTTP | Codes |
|---|---|
| 400 | `VALIDATION_ERROR`, `EMPTY_TURN`, `EMPTY_REQUEST`, `NO_INTAKE`, `REASON_REQUIRED`, `NO_PERMISSIONS`, `WRONG_PASSWORD`, `PASSWORD_REQUIRED`, `INVALID_TIMES`, `PATIENT_REQUIRED`, `INVALID_IDEMPOTENCY_KEY`, `SAME_SLOT` |
| 401 | `UNAUTHENTICATED`, `INVALID_CREDENTIALS` |
| 403 | `FORBIDDEN` (wrong role for the endpoint) |
| 404 | `NOT_FOUND` (missing, or not yours to see) |
| 409 | `SLOT_UNAVAILABLE` (with `details.alternatives`), `PATIENT_TIME_CONFLICT`, `IDENTIFIER_TAKEN`, `INVALID_STATUS`, `OFFER_NOT_OPEN`, `CONFIRMATION_INVALID`, `IDEMPOTENCY_KEY_REUSED`, `AFFILIATION_EXISTS`, `DEPARTMENT_EXISTS`, `SCHEDULE_OVERLAP` |
| 429 | `RATE_LIMITED` |
| 500 | `INTERNAL_ERROR` |
| 503 | `DATABASE_UNAVAILABLE`, `AI_UNAVAILABLE`, `SPEECH_UNAVAILABLE` |

The HTTP status for each code above is the intended mapping; because the API has not been
run, confirm against `/api/docs` and the integration tests.
